Why this shape. Everything here runs in one process against one file. There is no service boundary to cross, so a "call" is a Python function call and a transaction spans whatever it needs to. What would be a network contract in a distributed system is a module boundary here: deps.py decides access, models.py owns derived state, summary.py and cycle_math.py own arithmetic, and the routers own nothing but routing. The only moving part that can fail independently is Redis, and it is built to be absent.
